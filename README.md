# CodingRepo

## About this project

This is a personal learning project. The goal is to develop everything myself in order to learn and improve as a developer.

AI's role here is limited to that of a senior developer giving guidance:
- AI is used only in **ask mode** (no autonomous edits).
- AI explains concepts, reviews approaches, and suggests how to improve the code.
- All code changes are written by myself, not by AI.
